Dari Manual ke Lebih Rapi

Sebelum
  • Data tersebar di Excel
  • Status pekerjaan tanya lewat chat
  • Rekap laporan manual
  • Dokumen sulit dicari
Sesudah
  • Data tersimpan di sistem
  • Status terlihat di dashboard
  • Laporan bisa difilter/export
  • Dokumen tersimpan per data
